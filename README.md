# Aplikasi Python Sederhana - DevSecOps Pipeline

## 1. Nama Aplikasi & Fungsinya
Aplikasi ini dinamakan **Python DevSecOps Demo API**. Fungsinya adalah sebagai REST API sederhana berbasis Python Flask yang digunakan untuk mendemonstrasikan otomatisasi *pipeline* CI/CD dan keamanan perangkat lunak (*DevSecOps*).

## 2. Bahasa / Framework yang Digunakan
- **Bahasa Pemrograman:** Python 3.10
- **Framework Web:** Flask
- **Framework Testing:** Pytest

## 3. Cara Menjalankan Aplikasi
1. Pastikan Python sudah terinstal di komputer Anda.
2. Install semua dependensi yang diperlukan dengan perintah:
   ```bash
   pip install -r requirements.txt
